Reading the cut

Rows increase from left to right. Each arch joins a row to the row reached by moving its last bit to the front. Mint arches move forward, violet arches move backward. Bright arches cross the current row cut. A small loop denotes a fixed row. The diagram reveals the complete selected packet; only the last-column bits to the left of the cut are used as evidence below.

Below the arches, each line plots the forward crossing count at every cut for a possible last column with the same length, zero count and observed prefix. Gray traces have multiple cycles. Violet traces have one cycle and fail the selected backward test. Mint traces have one cycle and pass. The test reads bits along LF starting at row zero. Where several columns share a segment, each color occupies a band with width one plus 0.95 times the base-two logarithm of its count. The bands are drawn alongside the same data segment. At fixed zero count the sequence of profile slopes identifies the entire last column. A dashed ivory trace and its shaded area belong to the selected packet. The area adds the forward widths and equals the number of inversions in its last column.

Reading the field

Each rim starts at twelve o’clock and runs clockwise. Moving one place in either ordering advances one equal division of its rim. Each thread joins one word to itself. The intervening curves interpolate the angles; their length and crossings are properties of the drawing. Colour varies with the number of ones. The selected thread is ivory.

Lex compares bits from the left. Colex compares from the right. Grandmama orders the same windows by their starting positions in the cyclic concatenation of primitive roots of the length-n least rotations, taken in colex order. Time +1 advances the window by one bit in that cycle.

BWT packets group rotations of each primitive root. Within a packet, the row coordinate is its lexicographic rank among distinct rotations. The packet key is the last bit of each sorted primitive row, read down the column. Packets here are arranged by that key in ordinary string order, with a proper prefix first. This ordering across packets is a choice made for this experiment. The LF step moves the last bit of the selected window to its front and stays in its packet.

Mint ticks on a BWT rim mark rows that start with zero and end with one. Within a primitive packet their count equals the number of circular one-to-zero boundaries and the peak number of targets crossing a prefix cut in its stable shuffle. This count belongs to the packet. It measures the width of the counting procedure described in the accompanying investigation.
