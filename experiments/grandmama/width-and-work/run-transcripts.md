# A single-exponential bound for the complete cut at bounded crossing width

Candidate derivation, Codex, 27 November 2026. All earlier constructions remain available. This refinement combines the published block representation of binary necklaces with the comparison-transcript method from the preceding fixed-density investigation. The count applies to the entire population whose primitive roots have at most D circular zero runs. There is no restriction on how many times the bits of the threshold change. [Sawada, Williams and Wong, §2](https://www.cis.uoguelph.ca/~sawada/papers/neck_brgc.pdf) · [Earlier gap-value transfer](../fixed-density-gaps/README.md)

**Statement.** At explicit bit length n, for any binary threshold and fixed density, the weighted colex rank in this population can be computed in 6^D poly(n) bit operations and 2^D poly(n) space. Summing the density layers preserves these bounds. In particular each family D≤C log n, for fixed C, admits polynomial time. The previous order-type construction has a larger 2^{O(D log(D+1))} parameter factor.

**Which comparisons matter?** A primitive mixed least rotation consists of r positive run pairs (a,b), spelling a zeros followed by b ones. The least rotation begins at a zero-run head: a start in the middle of a zero run loses to its head, and a one cannot beat a zero. Among heads, comparing the pair letters in order (−a,b) gives the binary lex order. At the first unequal zero length the longer zero run wins. With equal zero lengths, the shorter one run wins when the other string still carries a one. If comparison is in the last block, equal length of the full cyclic spellings precludes one spelling ending at a discrepant final run while the other still continues. A period of the binary mixed circle preserves the set of zero-run heads, so a primitive binary circle is exactly a primitive cyclic sequence of pair letters. A bound on primitive width restricts r≤D.

For fixed r, the classical prenecklace extension rule generates a comparison transcript instead of the actual letters. With a valid prefix of length j and current Lyndon-prefix length p, a new letter may equal or exceed the letter at position j−p (zero-based); equality retains p, strict excess resets p to j+1. An exact Lyndon word at the end has p=r. Begin with one letter and p=1. Hence there are at most 2^(r−1) transcripts, each specifying a list of required equality and strict less-than edges. The prenecklace theorem gives both directions: every Lyndon sequence has exactly one accepting transcript, and all assignments realizing any accepting transcript are Lyndon. [Cattell et al., *Fast algorithms to generate necklaces, unlabeled necklaces, and irreducible polynomials over GF(2)*, fundamental theorem of necklaces](https://www.socs.uoguelph.ca/~sawada/papers/un.pdf)

**How the two orders coexist.** A forward-aligned primitive spelling read backwards has run lengths b_r,a_r,b_{r−1},a_{r−1},… beginning on one. Split the reversed threshold into disjoint first-differing-run cases. In one such case each earlier run length is fixed to a threshold constant. At the differing run a one length must be smaller, or a zero length larger. The remaining pair coordinates are unrestricted positive integers. Equal-length binary words with matching initial bit cannot first differ by one word ending while all its runs have matched. A threshold beginning on zero rejects every mixed candidate. A full upper sentinel accepts every candidate. This gives at most 2r boxes in pair-coordinate space. The component that decides a backward comparison is allowed to differ from the component that decides a forward comparison.

**Sum all assignments in a box.** Process all positive pair letters in increasing order of (−a,b) with a≤z and b≤n−z. Maintain the set I of already assigned slots and the two totals contributed so far. For the current letter assign a set J disjoint from I, including the choice of the empty set. All selected slots must admit the letter under the box constraints. Endpoints of each equality edge must join J together or both stay out; a strict edge whose larger endpoint joins J must already have its smaller endpoint in I. Add (a|J|,b|J|) to the totals, discarding overflows. End with every slot assigned and both totals exact. Every valid tuple yields one choice at each letter and vice versa. The pair alphabet has O(n²) letters, regardless of r. Across the layer there are at most 3^r ordered disjoint pairs (I,J) and O(n²) possible budgets. Edge tests, the stopping condition, and every count require polynomial bit work per transition. For example a partial state's assignments are bounded by (n²)^r and hence have O(n log(n+1)) bits since r≤n. At most two consecutive layers are needed. The polynomial includes the cut cases, sum over r≤D and finite primitive-divisor and density overheads.

For p dividing n let h=n/p. A length-p primitive root contributes p distinct rooted windows to the rank, at zero count z/h if h divides z. The reversed integer of its h-fold power is the root's reversed integer multiplied by (2^n−1)/(2^p−1). Dividing the cut by that factor and taking its ceiling gives the strict primitive cutoff. The two constant roots at p=1 have width zero and are treated separately. Applying the bound at every p proves the statement.

**Limits and checks.** This transfer can improve the parameter factor while a direct enumeration of ordinal types may still be faster on some small cases. Complete unrestricted rank sums over values of r extending linearly in n. The result concerns a restricted population, including all colex questions on that population. The independent rotation oracle checks every threshold including the upper sentinel, density, and relevant width cap for lengths one through eight.
