# What can be skipped in the colex tree?

November 26, 2026. Binary alphabet, lexicographically least rotations as representatives, zero-based strict ranks, and colex order on equal-length words. These are working arguments from this investigation, pending independent review and priority checks. Results about unrestricted thresholds are explicitly identified below.

## Reading the generation algorithm

Gabrić and Sawada, [Necklaces and Lyndon words in colexicographic order, v1](https://arxiv.org/html/2607.05324v1), §§2–4, 6. Definition 3 permits words meeting initial-run conditions in a superset of the necklace representatives. Theorem 4 bounds the *total* size of that superset by a constant times the total number of necklaces. The generator fixes a suffix, uses its minimum and run data to restrict the symbol to prepend (Lemma 6), and maintains the length r of its least nonempty suffix and the length p of a maximal terminal power of that least suffix. Section 4 updates r and p using comparisons of portions of the retained word. A small number of integer parameters accompanies an actual word buffer. Its contents participate in the comparison. The total work is constant amortized time per generated item; the final remarks leave efficient colex ranking and unranking open.

For example at order 12, take the length-six suffixes 001011 and 001101. In the binary 0,1 convention, both have runs=(0,2,1,2), suffix weight three, r=p=6 and j=6 free positions. Both are Lyndon. Thus even including the first and last symbols and Hamming weight gives the same proposed memoization key. For 001011 there are seven primitive completions and one period-six completion, for weight 90. For 001101 there are nine primitive completions and one period-six completion, for weight 114. The distinct left prefixes admitted only for the second are 000110 and 001101; the prefix 001011 gives a period-six completion in the first case and a primitive one in the second. The paper's actual generator retains enough information to distinguish these cases.

## A bound on linear summaries

Let n=2m, m≥2. Define W(w) as the least period of a representative, and zero on a nonrepresentative. Let C(a) be the sum of W(w) over keys strictly preceding a. Write L_m for the number of length-m binary Lyndon words. Consider the rational matrix indexed on both axes by those Lyndon words in **lexicographic** order, with entries W(xy). Below the diagonal x>y, so rotating by m positions gives yx<xy, forcing weight zero. On the diagonal xx is canonical with period m. The matrix is upper triangular with determinant m raised to the L_m power, so its rank is L_m. The same argument works for ordinary representative membership with diagonal one. For primitive-only membership one can instead shift the row and column lists by one to obtain an upper-triangular submatrix with nonzero diagonal: if x<y are Lyndon then xy is Lyndon, xx is not. Its rank is at least L_m−1.

The bound applies directly to **unrestricted weighted prefix counting**. Form the full matrix A(x,y)=C(xy) on binary halves. For each Lyndon x let x⁺ be the next m-bit key in colex order, which exists since x is not the all-one word. At fixed y the thresholds xy and x⁺y are consecutive, so A(x⁺,y)−A(x,y)=W(xy). Row differencing and column restriction cannot increase rank. Thus rank(A)≥L_m. For clarity, the triangular submatrix uses lex order to expose its diagonal, while the finite difference uses a colex successor. Reordering rows or columns does not affect rank.

Any exact arithmetic algorithm with a single cut between halves and a D-dimensional **linear** weighted-state interface, for example a one-pass weighted automaton or a matrix product with position-dependent transitions, factors its midpoint matrix as a product through dimension D. Consequently D≥L_m=(1/m)Σ_{d|m}μ(d)2^{m/d}, asymptotic to 2^m/m. Real or rational signed weights do not remove this bound. It applies equally to input read forward or backward. Scalar output on ordinary word membership and threshold counting are separate arguments. For thresholds promised to be primitive representatives many matrix entries are unspecified: the unrestricted threshold-matrix lower bound does not automatically extend. Arbitrary nonlinear states, revisiting the input, parameterized arithmetic aggregation and general polynomial-time evaluation are outside this lower bound. A high-rank comparison function itself can have a polynomial-time random-access algorithm.

## A polynomial bridge from arbitrary thresholds to boundary ranking

For nonempty suffix s and j free prefix positions, a canonical completion exists if and only if 0^j s is canonical. The same holds for primitive canonical completions. To prove the nontrivial direction, suppose some canonical completion xs has a one among its first j bits. If the completion is nonconstant, it ends with one and starts with a longest cyclic run of zeros of length L<j. Replacing x by j zeros creates a leading run of length ≥j. Every disjoint zero run remains wholly in s and is of length ≤L. Hence the new leading run is uniquely longest, guaranteeing both canonicality and primitivity. The all-one original with j>0 and nonempty s also yields this conclusion. If x was all zeros, the original already is the zero completion. The empty suffix is handled directly: a representative exists at every positive order and 0^(n−1)1 is primitive, including n=1. The j=0 case is the ordinary recognition test.

Reading from the right builds a binary key trie. In polynomial time find the least representative at or above a threshold: if the threshold itself qualifies use it, otherwise retain as long a key prefix as possible, increase its next zero to one, use the test above for feasibility, then greedily complete with the least feasible bit at each step. Return an end sentinel if none qualifies. The same algorithm works for primitive representatives. It is also possible simply to query a representative-only ordinary rank oracle on the next representative to get the insertion rank, using the standard total necklace count when the successor does not exist.

For weighted counts a primitive anchor rank oracle suffices. Find the first representative ≥ the threshold and move forward through representatives until reaching a primitive one or the end. By the [previous gap proof](../weighted-rank/README.md) the only adjacent pair of short blocks lies across the seam, so the number of short blocks traversed is bounded by two. If a primitive anchor is reached, subtract the lengths of the skipped short blocks from its absolute phase. If the end is reached, subtract their lengths from 2^n. Both produce the strict input threshold count. Conversely unrestricted C gives any primitive anchor rank outright. The archived local walk reduction extends anchor ranking to any observed window in polynomially many elementary operations. This is a polynomial-time oracle reduction and does not preserve one-pass finite-state width.

## Divisor inversion connects weighted and ordinary colex rank

Use integer keys T from 0 through 2^n (the latter is a terminal cutoff). The key of w is the binary numeral obtained by reversing w. For d|n put Q(n,d)=(2^n−1)/(2^d−1), and set T_d=ceil(T/Q(n,d)). Repeating a length-d word n/d times multiplies its key by Q(n,d). Therefore key(x repeated)<T if and only if key(x)<T_d. Nested cutoffs compose because Q(n,d)Q(d,e)=Q(n,e).

Let P_e(T_e) count primitive representatives at order e below the indicated cutoff. For each d dividing n, let R_d(T_d) count all representatives at d, and C_d(T_d) their total period weight. Decomposing by least period gives

    R_d(T_d) = Σ_{e|d} P_e(T_e)
    C_d(T_d) = Σ_{e|d} e P_e(T_e).

Given either oracle for arbitrary cutoffs, query it once for each d|n and invert the corresponding triangular system in increasing d. This recovers every P_e(T_e) and hence the other rank. Primitive-rank oracles can also directly supply the P_e, using the successor bridge for representative-only queries. The number of divisors, the bit lengths and elementary arithmetic overhead are polynomial in n; small terminal totals are computable by ordinary necklace or Lyndon enumeration formulas without listing. Conversely ordinary unranking and representative-only ranking interconvert by monotone binary search with endpoint totals; for primitive rank use the corresponding primitive list. A weighted threshold oracle also produces an observed window from a phase t. Binary-search for the least K with C(K+1)>t. This K identifies a positive-weight block, with offset t−C(K). Read the required n bits by concatenating primitive roots from that block and its successive representatives, using the zero-fill successor procedure and wrapping at the seam. At most n further nonempty blocks suffice. This is a one-direction reduction; no equivalence with an inverse-only clock oracle is asserted.

**Consequence.** With these binary conventions and the earlier gap/local recognition lemmas, worst-case polynomial-time arbitrary-window Grandmama ranking, weighted strict prefix counting, and ordinary necklace or primitive Lyndon colex ranking/unranking are polynomial-time Turing equivalent (the decoding claim here concerns ranking, not reconstruction of a word from an absolute tick). This identifies a precise remaining counting problem. It does not produce a polynomial-time algorithm.

## Checks

Run python3 tree_check.py. The script independently enumerates rotations and checks the explicit order-12 witness, zero-fill feasibility for every nonempty suffix at orders 2–12, conversion of a threshold to a bounded number of short blocks and an anchor, and both divisor inversions for every threshold including the end at orders 1–12. It also checks the triangular form and finite difference on every pair of length-2 through length-7 Lyndon words. Finite checks support the code and finite examples; the general claims use the arguments above.
