# The colex cut as a path in a stable shuffle

27 November 2026. Derivation, implementation and internal checks by Codex. Independent proof verification and priority assessment remain open.

## Decision

Change the primary exact-counting experiment from choosing successive minimum returns to summing a one-cycle constraint over binary stable shuffles. This is an exact reformulation of the **whole** rank. It removes the unknown canonical row at the outset. It does not give a polynomial evaluation algorithm. An explicit half-length contraction fails the total-work test if the individual row histories are visited. We give a symbolic alternative and identify the joint moments it needs. No stronger general upper bound is claimed than the archived candidate 2^{O(√n)}.

## 1. What would constitute a shrinking recursion?

For a polynomial toll per call, a sufficient accounting is a positive exponent c at least the toll degree and a uniform bound sum_i (n_i/n)^c ≤ theta < 1 on child sizes at every nonbase call (or an analogous bound on the number of distinct memoized states by level). Then induction bounds total work by a polynomial. Small individual children alone cannot do this.

The [shared-history reduction](../ordered-return-transfers/README.md) has one ordinary child m for a restricted family of ambient order n=6(D+2)m. That reduction really contracts. Its input is rank *within the encoded family*, while its child is unrestricted rank. These are different domains. For fixed parameters it covers 6(D+2)·2^{D+m} rooted words, by summing the scaled orbit periods over the fillers and token necklaces. The earlier proof does not give a disjoint full-population cover of polynomial total cost or an unrestricted-to-family call at smaller input size. Its converse embeds the general query into a larger restricted instance. Alternating the two directions does not reduce the original order. This is the reason to stop treating supplied minimum histories as the default recursion.

## 2. An ordinary rank as one-cycle itinerary counts

Let p be a primitive binary necklace length. Sort its distinct rotations in ordinary lex order, number the rows from zero, and let b be the string of their last bits. With z zeros in b, define a permutation P by stable sorting these bits. If i indexes a zero, P(i) is the number of zeros before i. If it indexes a one, P(i) is z plus the number of ones before i. Moving the last bit to the front of a sorted row sends it to row P(i): equal final bits are ordered by the rest of their rows. Thus b[0], b[P(0)], ... reads the canonical rotation backwards.

We use the classical BWT primitive-image criterion: binary strings b whose stable-sort permutation is a single p-cycle are in bijection with primitive necklaces. One way to see the inverse is to follow P backwards from each sorted first-column symbol. Within each first-symbol block the inverse order is increasing. Repeated refinement orders the forward itineraries lexicographically. If two itineraries coincide, equivalence classes are intervals of equal size along their cycle, transported in order, so returning to a class fixes every row in it. A single p-cycle forces the classes to be singletons (except the trivial length one). Thus row zero supplies the primitive least spelling. The transform, its cycle criterion and the broader multiset-of-necklaces correspondence are prior mathematics. [Gessel, Restivo and Reutenauer](https://people.brandeis.edu/~gessel/homepage/papers/necklace.pdf) · [MFCS 2025, BWT background](https://iris.unipa.it/retrieve/48fe4863-f6de-4c69-953f-bb9221de8c00/LIPIcs.MFCS.2025.48.pdf)

The proper-power terms cost only a divisor sum. For an n-bit cut with reversed integer key K and p dividing n, put S=(2^n-1)/(2^p-1). The reversed key of a repeated p-bit word is S times its primitive root's reversed key. Count primitive keys strictly below ceil(K/S) and multiply by p. Sum over p. At fixed density require the repetition count to divide the prescribed count. The strict cutoff splits into at most p disjoint binary prefix cylinders by its first differing bit (zero on the word, one on the cutoff). Thus computing every weighted rank reduces in polynomial overhead to counting one-cycle stable shuffles with a prescribed initial itinerary from row zero. A full-length prefix can be checked directly for primitive minimality. The archived boundary walk then translates rank to arbitrary Grandmama phase. This treats arbitrary cuts, constants and imprimitive words.

## 3. Contracting a prescribed path

Fix length n, 0<z<n, and k<n observed backwards bits s=b₁...bₖ. In a single cycle the rows i₀=0,i₁,...,iₖ visited by LF are distinct. Although their ranks are unknown, **their relative order is determined by the bits**. Row i_j begins with b_j...b₁ and then the row-zero continuation. For a first mismatch, ordinary lex order decides. If one of these finite strings is a proper prefix of another, the remaining comparison is between row zero and a distinct visited row. Row zero wins. Thus the visited rows are ordered by the finite strings empty, b₁, b₂b₁,...,bₖ...b₁, with a proper prefix first. Each noninitial row lies in the first-column block for b_j. This uses primitivity; a partial itinerary in an arbitrary multi-cycle permutation should not be assumed to have this order.

Choose concrete increasing row indices with that relative order and first-column membership. A pin i→j of bit c fixes b[i]=c and the number of zeros strictly before i: j for c=0, and i-(j-z) for c=1. Sort the pins by source. Subtract successive prefix counts, allowing for the pinned bit, to get a list of free intervals with lengths and zero quotas. Test all quotas for feasibility including the final interval. The product of the corresponding binomial coefficients counts all consistent fillings *before* imposing the single-cycle condition.

**Path contraction lemma.** Delete the k pinned source rows i₀,...,i_{k-1}, leaving the set U. Delete the k pinned targets i₁,...,iₖ, leaving the set V. A filling of the free intervals gives a residual binary word y of length n-k with those interval quotas. Its stable-sort permutation P_y maps the ordered U coordinates to ordered V coordinates: after deleting the pins, both bit lists still target the remaining zero and one destinations in order. To recover a permutation on U, redirect the surviving target 0 to iₖ. Following the removed chain from 0 would have ended there. All other common destinations retain their labels. In rank coordinates the redirection maps 0 to h, j to j-1 for 1≤j≤h, and fixes larger j, where h is the zero-based index of iₖ in U. Call it rho_h. The original permutation has one cycle iff rho_h P_y has one cycle. Contracting a simple directed path in this way preserves the number of cycles, including when one survivor remains. Conversely each quota filling recovers exactly one original pinned column. QED.

Thus the residual signature consists of ordered interval quotas and a single prefix rotation. Many original coordinates are disposable *after* a layout has been obtained. shuffles.py implements this identity, summing over z, layouts, disjoint cut cylinders and primitive lengths. Its residual evaluator enumerates quota fillings. This is a verification implementation and an exact general formula, not a performance replacement for the square-root bound.

## 4. Why almost halving the order fails to control total work

**Proposition.** There are primitive thresholds, a fixed half-density layer, and a single itinerary cylinder in each threshold decomposition for which the contracted order is (1/2+o(1))n and at least 2^{Ω(n/log n)} distinct feasible numerical paths occur. This rules out improving the archived upper bound by explicitly visiting every path in this direct contraction scheme. It says nothing about an algorithm that sums them together.

**Construction.** Choose m≥1 and ell=ceil(log₂(3m+1)). Encode an ell-bit integer with 0→0110, 1→1010; call the encoding C. It preserves lex order. Put H(j)=0001 C(j) 11, B=|H(j)|=4ell+6. Use one root block 00001 C(0) 111. Append m variable blocks, the i-th chosen independently from H(3i+1), H(3i+3), for 0≤i<m. Finally append the same probe tail H(2) H(5)...H(3m-1) in every word. Every word has length n=(2m+1)B+2, weight n/2, and a unique four-zero run at its start. Thus it is primitive and canonically spelled. The data encodings have no run of three zeros; fixed trailers separate them from the next delimiter.

Let k=mB and s be the reversal of the probe tail. Every one of these necklaces has the same first k backwards bits. The final bit of s is zero, hence s is an actual first-difference cylinder for the threshold whose reversed bits are s[:-1] followed by 1 and then n-k zeros. This threshold is itself primitive and lex-minimal because of its unique longest initial zero run. A trace of k edges includes the rotations beginning at every probe block. Before the probe H(3i+2) in the lex list are the root, the secondary 0001 row inside the root with code zero, two code rows for each previous i, and the i-th variable block precisely when its smaller option was chosen. All other starts with fewer leading zeros follow these rows. Hence the probe's zero-based row is

    2+2i+indicator{the i-th smaller block was chosen}.

The path determines all m independent choices. Its size is therefore at least 2^m different layouts across the fixed population, with k/n tending to 1/2 and m=Θ(n/log n). The symbolic proof applies to every m. The finite tests sort the rotations themselves through m=9. We have not shown that all these layouts require independent residual evaluations after arbitrary compression.

## 5. A path-free algebraic target

There is also a polynomial-size symbolic specification of the entire cylinder count. It pinpoints the missing operation. Form the polynomial Z(X) whose monomials are products over rows of X_{i,P(i)}, one monomial for each binary stable shuffle with z zeros (count multiplicities). Compute Z by a grid of prefix states (i,v) with v zeros used. A zero edge appends X_{i,v} and a one edge appends X_{i,z+i-v}. Disallow excess counts. Start at (0,0) and retain the final (n,z) state. This uses O(n²) arithmetic gates.

Let D_{ij}=X_{ij}∂/∂X_{ij}. On each monomial of Z this commuting operator has eigenvalue 0 or 1 according to whether edge i→j occurs. In the operator matrix D retain only columns of the destination bit c to get D_c. With the row/column zero removed in the cofactor, the cylinder count equals the following expression evaluated at all X=1:

    det((I-D) without row/column 0)
      · [e₀ᵀ D_{b₁} ... D_{bₖ} 1] Z(X).

To prove it, evaluate on one edge monomial. The matrix product reads the prescribed LF itinerary, with bits determined by the destination's first-column block. The cofactor is one on a single cycle and zero otherwise. Indeed on deleting row zero the single cycle is broken into a path and gives determinant one; an unbroken other cycle makes the determinant zero. Now use linearity. This is an identity over commuting operators, not ordinary evaluation at mean edge frequencies. Compact syntax for a polynomial and a differential functional does not in general give a polynomial-time pairing algorithm. That pairing, or an equivalent dynamic program for joint edge information, is a specific general target outside return-word elimination.

**Independent residual evaluation.** For a pinned signature use the same cofactor on rho_h P_y. Expand it as a sum over subsets S of the surviving rows excluding row zero. A principal permutation minor vanishes unless P_y maps S to rho_h^{-1}(S). Otherwise its sign is that of the restricted ordering, corrected for moving target zero past targets 1,...,h. For fixed S the signed sum is computable by a binary grid dynamic program: process the source rows in order, track zeros used, enforce the interval quotas, and require membership of each source in S to equal membership of its raw target in rho_h^{-1}(S). An inversion is incurred for each earlier selected one when a selected zero is placed. The number of those ones is already determined by the consumed prefix of the ordered one-target list. The final twist sign is the parity of the selected targets crossed by raw zero if selected. Multiply by (-1)^|S| from the cofactor expansion. This is polynomial work per subset, exponential in residual order in general, with polynomial working space. minors.py checks it against literal completions.

**When averaging is exact, and when it fails.** If the uncertain quota intervals are independent length-two blocks with one zero each and all other intervals are forced, each switch exchanges the targets of two rows. Its two permutation matrices differ by rank one, and the updates from the switches add because every interval's total counts are fixed. The cofactor determinant is affine in each rank-one switch parameter separately. Independence then makes its mean equal to the cofactor of the mean matrix. The integer count is that cofactor times the number of assignments. The test with 32 binary switches and zero twist gives 67,108,864 one-cycle completions out of 2^32. For one three-position interval with one zero and zero twist, the exact count is 1; taking the cofactor after averaging predicts 2/3. Thus marginal edge probabilities alone cannot be substituted into this formula. Higher joint minors, or cancellations that account for them, are essential to this strategy.

## Assessment

| Approach | General coverage | What the work test says |
|---|---|---|
| Minimum histories and ordered transfers | Earlier exact square-root upper bound; polynomial evaluation with supplied histories | Retain as benchmark. One-call shrink in the shared-history family does not cover the full population. |
| Explicit BWT paths and contraction | All binary thresholds, periodic terms and fixed density | The origin is row zero and contraction is exact. Branch count defeats a recursion enumerating layouts even at constant-factor size decrease. Deprioritize enumeration. |
| Stable-shuffle polynomial paired with a cycle cofactor and itinerary | Same full target | No list of candidate origins or numerical paths in the identity. Some exponential sums collapse exactly. General joint-minor evaluation remains unbounded by any proved polynomial. Prioritize testing this operation against known shuffle/descent and determinant identities before extending the representation further. |

The eight-bit witnesses remain distinguished. At key 184 the two primitive BWT last columns are 10111000 and 11010100; following LF from row zero gives opposite answers. The winning origin here is already given; computing the joint weight of its past and the global connectivity condition still demands work. This locates a different dependency than candidate multiplicity. It is a statement about these representations, not about an intrinsic lower bound on temporal knowledge.

The audit independently sorts rotations, tests every threshold through order seven plus selected order-eight cuts, compares fixed-zero layers, checks individual feasible and impossible pinned layouts, and tests the probe family.
