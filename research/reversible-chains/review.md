The review used the Proof Craft entry, mathematical-writing reference, Halmos exposition appendix and finite-reduction appendix, consulted at commit `46f6f6b` of [Proof Craft](https://github.com/fitelson/proof-craft). ## Correctness

**What a state counts.** Two assignments to the observed coordinates are equivalent precisely when every completion gives the same requested output. A shared memory state must return one answer for each completion. Conversely, a residual function is sufficient memory because the next input restricts that function. This proves necessity and sufficiency in the fixed, deterministic read order, with the position and query specified in advance unless a delayed query is explicitly stated. The number of bits for a fixed-length state encoding is the ceiling of the base-two logarithm of the number of residual functions. Transition-table construction, arithmetic cost and the reader's control program are separate quantities.

**One-step comparison.** For length $2q$, $q\ge1$, the matched XOR and OR questions use the initial right-edge bit plus the parity of the odd-site changes. Under OR, the coefficients on the first $q-1$ unseen odd bits recover all but the first even bit. The response on the zero odd suffix supplies that final bit. Under XOR only the parity of the evens survives. The last odd bit makes the answer balanced in both cases. Setting all bits of the opposite parity to zero witnesses essential dependence on each individual input. At $q=1$ both rules give two states, as the boundary removes the mixed term. Replacing changes by raw updated odd-site parity preserves the row counts after adding a fixed suffix function but can change essential support. The controlled support comparison uses the stated two-time question.

**Quadratic predictor.** For a one-step parity of selected updated coordinates, split initial variables into observed $u$ and unseen $v$. Removing terms common to every residual leaves an offset $p(u)$ and slope $M^Tu$ on the unseen bits. Distinct slopes are distinguishable. Let $r$ denote the rank of the slope map. With $K=\ker M^T$, offsets in a slope class vary by $p(k)+p(0)+B(u,k)$ for $k\in K$, where $B$ is the polar form of $p$. If $B$ is nonzero on $K\times K$, the variation cannot vanish identically on any class. Otherwise the condition for a constant offset is linear in $u$, factors through $u+K$, and can be checked on a basis of $K$. If inconsistent, every class splits in two. If consistent with rank $h$, exactly $2^{r-h}$ of the $2^r$ slope classes stay whole. This explains the subtraction in the implementation as well as $h\le r$. In the empty-cut or constant-query cases the same argument remains valid. Squaring a Boolean variable is understood as the variable itself. The predictor assumes valid site masks for the chosen length and one time step.

**The nonlinear ladder.** For rule 4 fix an endpoint $i$ and put $e_s=x_{i-2s}$, $a_s=x_{i-2s+1}$. Set $F_0=x_i$ and $F_j=(1+e_j)a_1\cdots a_j$ for $j\ge1$. Negative sites are zero. This extension evolves consistently because the all-zero configuration is fixed. The recurrence follows from two identities. Under the factor $1+e_j$, the product of the updated gates equals the old product. The same holds under the factor $a_{j+1}$. Indeed either condition gives $a'_j=a_j$. If a gate vanishes, the zero of largest index stays zero since the gate on its right is one, or it is the last gate. If all gates are one, each stays one. Applying the identities to $1+e'_j=1+e_j+a_{j+1}(1+e_{j+1})$ gives $F'_j=F_j+F_{j+1}$. The case $j=0$ follows from the update. Binomial expansion of this shift on functions gives the finite sum for every nonnegative time. For odd $i$, the term with $j=(i+1)/2$ can contribute via a fixed coefficient one. Dropping it gives the wrong answer already at $i=t=1$.

**Three observations and delayed times.** At even $i=2r$, write $J$ for the active positive binomial indices through $r$. In increasing spatial order the nested expression uses one bit, alternately adding an active coefficient and multiplying by its gate. After all even coordinates arrive, the independent nested gate monomials and the constant give $2^{|J|+1}$ residuals. Independence can be checked by evaluating on successively longer prefixes of ones followed by zeros. After all odd coordinates arrive, only the number of active monomials preceding the first zero matters. All $|J|+1$ such possibilities occur and independent unseen coefficients separate them. The two grouped counts refer to specified cuts. For a delayed choice among times, the entire initial assignment is discarded before the choice is revealed. Every vector of features $F_0,\ldots,F_r$ is realized by setting all gate bits to one and varying the $r+1$ even bits. Thus exactly $2^{\mathrm{rank}(B)}$ different answer lists occur for the binomial time matrix $B$ over the binary field. The empty list and $r=0$ obey the formula. This is a statement about retained memory at the handoff. A streaming algorithm may use other memory earlier. At odd endpoints the all-gates-one witness fixes the last coefficient, so an extension requires its own argument.

**Arbitrary cuts for rules 4 and 2.** Fix the first zero among the known gates, or the sentinel beyond the last gate if none is zero. The first zero among unseen gates determines an ordered list of suffix cases, all attainable. Each included data coefficient before the known stop contributes a step vector over this list. Different steps are independent by first differences. A surviving unseen data bit labels its own nonzero step, so differing surviving index sets yield disjoint response families. For a fixed set of surviving unseen data indices, previously observed bits supply free steps. As the known stop moves outwards those spans are nested. Only the largest span for each fixed boundary offset matters. A forced final ghost coefficient can translate that span by one step. If the step belongs to the larger span the two families merge there, and otherwise their overlap is empty. The integer count in arbitrary_cut.py implements this union. Complementation for rule 2 changes the ghost colour, which removes the possible last term with a negative data index. These arguments use the nested products particular to these rules.

## Exposition and evidence

The most informative distinction for a first reading is between remembering an answer and remembering how that answer would change under each remaining observation. The XOR example permits the first summary. The OR example requires the second because each observed even bit can independently decide whether one future odd bit matters. Both systems preserve their complete input states under evolution, while each question returns one balanced bit. No appeal to lost information is needed.

Three refinements resulted from this review. The comparison specifies the temporal question that matches essential support. The single-site results label the read cut and the handoff explicitly. The ladder carries fixed boundary bits through the algebra. The one-step quadratic classifier and the arbitrary-cut ladder computation evaluate different observables and have different time scopes.

The finite census tests a specified range of sizes, phases, rules, observables and orders. The supporting scripts include direct evolution and direct grouping of answers on all completions for small lengths. These computations give reproducible checks on the formulas and their implementation. They supply no inference from sampled lengths to an asymptotic claim. The XOR/OR midpoint separation uses a standard inner-product communication mechanism. The dyadic prediction formula for rule 4 has a published antecedent. Specific all-time, cut and family formulas remain subject to external review and a fuller priority search.
